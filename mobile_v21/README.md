# Mustang mobile_v21

Мобільна вебверсія на базі `mustang_gui.21_ai.py`.

Ця версія винесена окремо, щоб не ламати чинну вебверсію з кореня репозиторію.

## Що перенесено
- дошка 8×8 і логіка слонів/коня;
- AI коня з поточного вебрушія;
- автоматичне керування слонами GPT#1–GPT#20;
- CycleGuard 2–5 для автоматичної серії;
- рівні 32/24/16/14/12 та власна кількість 1–32;
- пауза із прихованими фігурами;
- збереження / продовження через localStorage;
- відміна ходу з підтвердженням та позначенням результату;
- нотація та replay;
- локальні та світові рекорди;
- 3 кампанії з ім'ям і паролем для продовження на цьому пристрої;
- mobile-first інтерфейс і підтримка landscape.

URL після GitHub Pages:
https://teachersergiy-wq.github.io/mustang/mobile_v21/

> Пароль кампанії у цій версії є локальним ключем браузера, а не серверним акаунтом.
