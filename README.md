# Мустанг — статична веб-версія (без сервера)

Гра працює повністю в браузері. AI коня — у JavaScript.

## Як відкрити локально

1. Розпакуй папку `mustang-static`
2. Відкрий `index.html` у Chrome (подвійний клік або перетягни у вікно браузера)

Або з терміналу:

```bash
cd mustang-static
# Python
python -m http.server 8080
# потім http://127.0.0.1:8080
```

## Як викласти на GitHub Pages

1. Створи репозиторій на GitHub
2. Завантаж уміст цієї папки в корінь репозиторію
3. Settings → Pages → Source: Deploy from branch `main` / folder `/ (root)`
4. Через 1–2 хв відкриється:
   `https://ТВІЙ_ЛОГІН.github.io/НАЗВА_РЕПО/`
