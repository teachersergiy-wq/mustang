# Мустанг — веб-версія (без сервера)

Посилання (приклад): https://teachersergiy-wq.github.io/mustang/

## Що є

- Гра в браузері (AI локально)
- Мобільний інтерфейс
- Рекорди на пристрої (localStorage)
- Світові рекорди через Google Apps Script / Таблицю

## Локальний запуск

Відкрийте `index.html` або:

```bash
python -m http.server 8080
```

## Підключення світових рекордів (крок 7)

### 1. Google Таблиця + Apps Script

1. Створіть нову Google Таблицю.
2. Розширення → Apps Script.
3. Вставте код з файлу `apps_script/Code.gs`.
4. Розгорнути → Нове розгортання → Вебзастосунок
   - Виконувати як: Я
   - Хто має доступ: Усі
5. Скопіюйте URL (`https://script.google.com/macros/s/.../exec`).

### 2. У грі

Відкрийте `js/config.js` і вставте URL:

```js
APPS_SCRIPT_URL: "https://script.google.com/macros/s/XXXX/exec",
```

Завантажте оновлені файли на GitHub Pages.

### 3. Перевірка

1. Виграйте партію → ім'я → Зберегти рекорд.
2. Рекорди → На пристрої.
3. Рекорди → Світ (після підключення URL).
